The Claude Code Agents marketplace includes 182 specialized agents organized into nine major domains. Each entry shows the agent name, its model tier (`opus` / `sonnet` / `haiku` / `inherit`), the plugin that bundles it, and a short description of what it does and when to invoke it.

<Note>
Agents are installed as part of a **plugin** — not individually. Use `/plugin install <plugin-name>` to make the agents in that plugin available in your session.
</Note>
