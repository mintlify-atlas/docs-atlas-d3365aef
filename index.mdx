## Get started in two steps

<Steps>
  <Step title="Add the marketplace">
    Register the full catalog of 77 plugins in Claude Code. This loads no agents or tools into your context yet.

    ```bash
    /plugin marketplace add wshobson/agents
    ```
  </Step>
  <Step title="Install the plugins you need">
    Each installed plugin loads only its specific agents, commands, and skills.

    ```bash
    /plugin install python-development
    /plugin install backend-development
    /plugin install security-scanning
    ```
  </Step>
</Steps>
