Every installed plugin contributes namespaced slash commands to Claude Code. The full collection spans 96 commands across 12 functional categories — from scaffolding a new backend service to running a multi-framework compliance check. Each command follows the same format: `/plugin-name:command-name [arguments]`. Use `/plugin` at any time to list commands from your currently installed plugins.

## Command arguments

Commands accept free-form text arguments and structured flags. Flags use `--flag-name value` syntax:

```bash
# Free-form text argument
/backend-development:feature-development OAuth2 integration with social login

# Flag-based argument
/security-scanning:security-hardening --depth comprehensive --compliance owasp,soc2

# Combined
/full-stack-orchestration:full-stack-feature "payment processing" --stack react/fastapi/postgres --api-style rest
```

Argument hints for each command are shown in the tables above using angle brackets for required values (`<value>`) and square brackets for optional values (`[value]`). The pipe character (`|`) separates mutually exclusive options.
