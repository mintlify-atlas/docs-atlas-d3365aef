The Claude Code Agents marketplace ships 77 focused, single-purpose plugins organised into 24 categories. Install only the plugins your project needs — each one loads its own agents, commands, and skills without touching the rest of the marketplace.

```bash
# Register the marketplace (one-time setup)
/plugin marketplace add wshobson/agents

# Install any plugin below
/plugin install <plugin-name>
```
