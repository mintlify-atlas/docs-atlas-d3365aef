## What is Claude Code Agents?

Claude Code Agents is a unified repository of **77 focused plugins** organized into 24 categories. Each plugin is a self-contained unit: install it and only its specific agents, commands, and skills load into Claude's context. Install nothing and nothing loads — no wasted tokens.

The system ships with:

- **77 plugins** — granular, single-purpose units optimized for minimal token usage
- **182 specialized agents** — domain experts across architecture, languages, infrastructure, quality, data/AI, documentation, business, and SEO
- **149 agent skills** — modular knowledge packages with progressive disclosure
- **16 workflow orchestrators** — multi-agent coordination for full-stack development, security hardening, ML pipelines, and incident response
- **96 commands** — project scaffolding, security scanning, test automation, and infrastructure setup

## What makes it unique

**Granular by design.** The average plugin contains 3.6 components (agents + commands + skills), following Anthropic's recommended 2–8 component range. This keeps each plugin focused, fast to load, and easy to compose.

**Progressive disclosure for skills.** Skills use a three-tier architecture — metadata is always loaded, core instructions activate on demand, and reference resources load only when needed. A skill that is never triggered adds virtually zero token cost.

**Three-tier model strategy.** Agents are assigned to Opus, Sonnet, or Haiku based on the cognitive demands of their work. Architecture and security reviews use Opus 4.6 (80.8% SWE-bench score). Documentation and testing use Sonnet. Fast operational tasks use Haiku. A fourth `inherit` tier lets you override the model at session start for cost control.

**Install only what you need.** Installing `python-development` loads 3 Python agents, 1 scaffolding command, and makes 16 skills available — approximately 1,000 tokens. The other 76 plugins remain inert until you install them.
